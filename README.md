## Project Description

CSE Exam Tutor is an AI-based educational assistant designed to help Computer Science and Engineering students prepare for examinations.

The project uses a pre-trained Large Language Model (LLM) adapted through Low-Rank Adaptation (LoRA) fine-tuning to provide subject-focused answers.

Students can enter questions and receive clear, structured answers based on examination mark categories such as 2-mark, 5-mark and 10-mark formats.

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- PEFT (Parameter-Efficient Fine-Tuning)
- FastAPI
- React

## Project Objective

To develop an AI-powered study assistant that provides relevant explanations and examination-oriented answers, making CSE exam preparation more accessible and organised.
